# M3 — robot collider comparison

Fresh raw USD parse exactly reproduces both historical contact and support manifests; hashes verified. Target asset is installed mjlab G1 selected by tracking_env_cfg.py, not the source repository custom G1 XML. All wrist and ankle colliders, including disabled visuals, are listed in robot_audit.json with compiled transforms and settings.

Native: each wrist pitch link has a radius .035 m capsule, endpoints [-.01,0,0] and [.06,0,0]. Each wrist yaw link has a radius .035 m hand capsule, endpoints [.07,0,0] and [.15,∓.02,0]. HDMI: three boxes per wrist yaw, no wrist pitch capsule; half-sizes [.05,.025,.025], [.05,.01,.05], [.025,.01,.05], centers [.02,0,0], [.09,0,0], [.15,∓.01,0], final box yaw ∓.4 rad. The first two overlap in x by 3 cm. Full internal pair distances are evaluated in M4.

Native feet: seven radius .01 m capsules each; HDMI: four radius .005 m spheres each. Existing adapter changes both hands and feet; it must not be ported wholesale. Geometry agrees with raw USD within float precision, but default contact parameters and robot inertias do not thereby become PhysX-equivalent. Visual meshes remain noncolliding.

Decision: preserve native robot; provide a separately named, opt-in hand-only comparison profile. Keep native feet. No training activation.
