# Executed physical tests

36 primary cases: native/HDMI hand-only × support raise 0/4/10 mm × reset frames 250/400/530/550/839, plus six isolated box-only initial/final support cases. Durations 1.2/1/2/3/3 seconds respectively, box-only 3 seconds. Six named 2.5 ms sensitivity cases repeat key 400/530 failures and final isolated settle.

Primary dt=.005 s, 50 Hz command held for exactly four steps, implicitfast, pyramidal friction cone, iterations=10, ls_iterations=20 (native Reproduced solver settings). Half-step repeats hold commands for eight steps, original PD unchanged. CPU MuJoCo; no claim of bitwise MuJoCo-Warp parity. Scene generation uses actual get_g1_robot_cfg → Entity and its built-in position actuators. Compiled gains, damping, effort ranges and armatures match the original model; all are recorded in each summary. Inverse action affine mapping reconstructs the exact source joint setpoint; action noise and domain randomization disabled, nominal native evaluation foot friction=1. No velocity feedforward, no gain retuning, no root/box actuator, no weld/equality/mocap, no post-reset pose or velocity write. qfrc_applied and xfrc_applied are asserted zero at every physics sample.

Initial root/joint/object positions and velocities come from the original full HOI NPZ; body-local angular free-joint qvel is obtained by rotating the supplied world angular velocity. Source NPZ is never written. Independent resets isolate windows but may start with deep measured penetration. Each trace labels reference frame and initial penetration; no hidden settling removes the overlap. At the last clip frame the original last joint target is held solely for the terminal stability probe, not counted as episode completion/training success.

Per-step trajectory.csv records actual object pose/speed/rotation error, free root height/error, joint RMS tracking error, force sums, penetration and cumulative slip. contacts.csv records every box contact geom pair, signed dist, actual mj_contactForce normal and tangential components, normal direction, world position and relative tangential speed. Per-side forces are sums of positive normal magnitudes, not net Cartesian resultant or actuator torque. Slip is contact-force-weighted relative point tangential speed integrated only while normal force >1 N; it is surface slip path, not net box drift. Box drift/trajectory is separately recorded.

Bilateral contact fraction uses actual >1 N on both hands during reference desired-contact samples; intent itself never counts as contact. Stable terminal box: last .5 s continuously supported >1 N, root speed <.02 m/s, angular speed <.1 rad/s, orientation error <.05 rad, final position error <.02 m. This explicitly tolerates gravity settling from the recorded 10 mm gap; it does NOT pass the original 1 mm reference/support consistency gate. Root collapse is logged independently at pelvis Z <.35 m and does not turn a stable box into a successful robot task.

All 36 primary and 6 sensitivity cases completed. The earlier three-case dynamics_smoke archive is excluded from conclusions because its first command-clock implementation rounded rather than held frames; STATUS.md preserves that correction. No failed run was overwritten. 7 focused validation tests passed. Tests prove the harness contract/measurements, not M7 readiness.
